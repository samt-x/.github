# samt-x/.github

Felles standardfiler for repoene i organisasjonen `samt-x`.

`.github/ISSUE_TEMPLATE/` har ett skjema per issue type (Task, Solution proposal, Question, Decision, Risk og Problem). Skjemaene gjelder alle repoer i orgen som ikke har egne skjemaer. Et repo med egen `.github/ISSUE_TEMPLATE/` bruker bare sine egne.

Konvensjonene for typene, innspill og lukking står på [docs.samt-bu.no](https://docs.samt-bu.no/prosjektleveranser/loesninger/samhandlingsplattform/oppgavestyring/konvensjoner/). Oppsettet er dokumentert i [solution-task-management](https://github.com/samt-x/solution-task-management), og arbeidet er sporet i [solution-task-management#17](https://github.com/samt-x/solution-task-management/issues/17).
